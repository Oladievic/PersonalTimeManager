# Пробка — доска времени

Личный офлайн-first менеджер времени: пробковая доска со стикерами, «второй мозг» по сферам и необязательный мост MCP, через который ChatGPT или Claude могут создавать и править дела.

- **Windows** — открывается в браузере, устанавливается как PWA.
- **Android** — та же PWA, устанавливается на главный экран, работает офлайн.
- **Без сборки** — HTML, CSS и классический JavaScript. Никаких npm, Node.js и бандлеров.
- **Без сервера** — данные в IndexedDB (запасной вариант — localStorage). Сервер нужен только для синхронизации и MCP.

---

## Быстрый запуск

1. Установите [Python 3.10+](https://www.python.org/downloads/) и включите **Add Python to PATH**.
2. Дважды щёлкните `run.bat`.
3. Приложение откроется на `http://localhost:8765/`.
4. В окне сервера будет токен для MCP.

Если Python нет, приложение всё равно можно открыть как обычный `index.html`, но PWA-установка, синхронизация и MCP требуют HTTP-сервер.

### Android

1. Запустите сервер на компьютере.
2. Узнайте локальный адрес — сервер печатает его при старте, обычно `http://192.168.x.x:8765/`.
3. Откройте этот адрес в Chrome на телефоне (компьютер и телефон в одной Wi-Fi сети).
4. Меню браузера → **Установить приложение** / **Добавить на главный экран**.

Для работы вне дома нужен туннель или VPN; сама PWA при этом продолжает работать офлайн с локальными данными.

## Что внутри

### Доска — главный экран

Доска открывается при каждом запуске. Остальные экраны — «Сегодня», «Задачи», «Календарь» и сферы — остаются доступны из левого меню как вспомогательные представления.

- На бумажках видно только главное: название, короткий фрагмент описания, срок, прогресс чек-листа и теги.
- Клик по бумажке раскрывает подробную карточку: она вырастает из наклейки и показывает полный текст, ссылку, файлы, чек-лист и все поля.
- Стикеры разных цветов, форм и креплений: скотч, кнопка, без крепления.
- Свободное перемещение, поворот, изменение размера, магнитная сетка.
- Нити между заметками, подписи и стили линий.
- Несколько досок; «Входящие» встроены.
- Масштаб, панорамирование, мини-карта взгляда, горячие клавиши.
- Богатый текст, чек-листы, файлы, теги, ссылки — в подробной карточке.

### Сферы

| Сфера | Что живёт внутри |
|---|---|
| **Работа** | VPN Pipster, смены, база ответов, шаблоны |
| **Учёба** | ДЗ, предметы, конкурсы, портфолио, релизы |
| **Проекты** | Своё Android-приложение, идеи, этапы, релизы |
| **Личное** | Журнал, важные даты, здоровье, семья |

### Вспомогательные экраны

- **Сегодня** — три главных, задачи дня, прогресс, фокус.
- **Задачи** — список и матрица, фильтры по сферам и срокам.
- **Календарь** — дедлайны по дням.
- **Входящие** — быстрый разбор без обязательной сортировки.
- **Работа / Учёба / Проекты / Личное** — сценарные экраны со своими действиями.
- **Обзор** — итоги недели, фокус по сферам, цели.
- **Поиск** — сквозной по названиям, текстам, тегам и предметам.

### Принципы

- Обязательно только название.
- Сначала поймать, потом разбирать.
- Вместо удаления — архив (удаление остаётся, но спрашивает подтверждение).
- Минимум ритуалов: никаких обязательных ежедневных отчётов.
- Универсальные дедлайны и повторения: день, неделя, месяц, год, будни.

## Данные и резервные копии

- Основное хранилище — **IndexedDB**, запасное — `localStorage`.
- Экспорт `.probka` содержит доски, заметки, нити и вложения (base64).
- Импорт заменяет текущий документ; перед импортом приложение делает резервную копию.
- Автоматические копии документа хранятся в IndexedDB.
- Сервер хранит свою копию в `data/doc.json`, токен — в `data/config.json`, резервные копии — в `data/backups/`.

Папку `data/` не стоит выкладывать в публичный репозиторий.

## MCP и ChatGPT

Подробная инструкция: [`docs/MCP.md`](docs/MCP.md).

Коротко:

1. Запустите `run.bat`.
2. Для ChatGPT поднимите HTTPS-туннель, например `cloudflared tunnel --url http://localhost:8765`.
3. Создайте коннектор с адресом `https://ваш-туннель/mcp/ТОКЕН`.
4. В приложении: **Меню → ChatGPT и MCP** → включите синхронизацию.

Claude Desktop может запускать сервер локально в режиме stdio — см. `docs/MCP.md`.

## Ограничения

- Напоминания и уведомления работают, только пока приложение открыто.
- Нет глобальной горячей клавиши Windows и фоновой синхронизации при закрытом приложении.
- Вложения не передаются через MCP.
- ChatGPT требует публичный HTTPS; туннель — внешний сервис.
- Синхронизация разрешает конфликты по времени изменения, а не по смыслу.
- Это персональный инструмент, а не многопользовательская система.

## Разработка

Сборка не нужна. Правьте файлы и обновляйте страницу.

```powershell
# запуск с автоперезагрузкой страницы вручную
python server.py --port 8765 --open

# только stdio для Claude Desktop
python server.py --stdio

# перерисовать иконки (нужен Pillow)
python tools/make_icons.py
```

Сервер отдаёт статику с `Cache-Control: no-cache`, поэтому изменения JS и CSS подхватываются после обычного обновления. Если установлен service worker, при обновлении версии поднимите `VERSION` в `sw.js`.
