# ТЗ / Промпт — «Второй мозг + командный центр» для одного человека

Приложение личного тайм-менеджмента, покрывающее 4 сферы жизни:
**Работа (техподдержка VPN Pipster)**, **Учеба**, **Личные проекты (мобильное приложение)**, **Личная жизнь**.

---

## 1. Философия и ключевые решения

1. **Одна система, не четыре.** Самая частая ошибка — отдельное приложение на каждую сферу (Notion для учебы, отдельная база для работы, памятка на телефона...). Итог: половина дедлайнов теряется между системами. Здесь всё живёт в одной базе данных, а сферы — это лишь **метка «контекст»** на каждой записи.
2. **Дедлайн — универсальное свойство.** Любой объект (задача, ДЗ, встреча, конкурс, релиз) может иметь дедлайн + напоминание. Не плодить отдельные «таблицы дедлайнов» — единый механизм.
3. **Захват важнее организации.** Идея или дело должны фиксируются за 2 секунды, сортировка — потом. Отсюда: глобальный хоткей → поле ввода → всё в «Входящие».
4. **Только название обязательно.** Все прочие поля опциональны и заполняются по мере необходимости. Минимум трения = система реально используется.
5. **Архив вместо удаления.** История задач/идей — это данные о себе (аналитика, что успеваю, что откладываю).
6. **Минимум обязательных ритуалов.** Максимум — два: утреннее планирование (1 мин) и еженедельный обзор (15 мин). Всё остальное приложение подталкивает само, а не требует.

---

## 2. Навигация (структура приложения)

Левое меню / нижняя навигация:

| Раздел | Что там |
|---|---|
| **Сегодня** | Главный экран-дашборд |
| **Задачи** | Единый список задач всех контекстов, фильтры |
| **Календарь** | Неделя/месяц: дедлайны, встречи, ДЗ, конкурсы |
| **Входящие** | Неразобранные записи |
| **Работа** | База знаний + шаблоны ответов |
| **Учеба** | ДЗ, портфолио, ссылки, конспекты, конкурсы |
| **Проекты** | Роадмапы, идеи, бэклог личного приложения |
| **Жизнь** | Журнал, личные дела, таймеры |
| **Обзор** | Ритуал еженедельного обзора + аналитика |
| **Поиск** | Глобальный поиск по всему |

Каждая запись в системе имеет поле **«Сфера» (context)**: `Работа | Учеба | Проекты | Личное` — с цветом. Это главный способ фильтрации и окраски интерфейса.

## 3. Модули подробно

### 3.1. Дашборд «Сегодня» ✅ ядро

Один экран, заменяющий 6 приложений:
- **Просроченное** (красным, всегда сверху; кнопка «перенести» в 1 клик)
- **Дедлайны сегодня** 
- **Встречи/звонки сегодня** (со временем и ссылкой)
- **3 главных дела дня** (заголовок: «Сегодня главное» — человек сам выбирает утром, не автоматика)
- **Блок по текущему контексту:** пункт «Я на работе?» → показывает только рабочие дела и шаблоны. Учеба → ДЗ и конкурсы. Идея «переключателя контекста дня/времени»: по расписанию (например, 9:00–18:00 будни) дашборд подставляет приоритетную сферу.
- Быстрые кнопки: «+ задача», «+ идея», «+ встреча», «запустить таймер»
- Внизу — прогресс дня: закрыто X из Y.

### 3.2. Задачи (единая сущность)

Поля задачи:
- `Название` (обязательное), `Заметки`
- `Сфера` (обязательная, но по умолчанию — последняя использованная)
- `Дедлайн` (дата/дата-время) + `Напоминание` (за N минут/часов/дней — свой для каждой задачи)
- `Приоритет`: 🚨 срочно-важно / обычная / когда-нибудь (матрица Эйзенхауэра упрощённая — вычисляется полуавтоматом из дедлайна и важности)
- `Проект` (опционально — привязка к проекту из 3.7)
- `Повторение`: ежедневно/по будням/еженедельно/по датам (для рутины: «написать отчет», «занятие по...»)
- `Оценка времени` (мин): 5 / 15 / 30 / 60 / 120+ — быстрые чипы
- `Статус`: Входящие → Сегодня → В работе → Сделано → Архив

Функции:
- Представления: Все / Сегодня / Неделя / Просроченные / По сферам / По проектам / Матрица Эйзенхауэра (4 квадранта drag&drop)
- Перетаскивание между списками и датами
- «Отложить» одним свайпом/кнопкой: +1 день, +3 дня, завтра, следующая неделя
- Подзадачи (чеклист) без ограничения вложенности [не глубже 2 уровней]
- Повторяющиеся: при закрытии создается следующий экземпляр, история сохраняется

### 3.3. Дедлайны и напоминания (ядро №2)

- Единый механизм для всех типов объектов (задача/ДЗ/встреча/конкурс/релиз).
- Виды напоминаний: точное время, «за N минут», «заранее за N дней», «утром в день Х».
- **Утренний дайджест** (пуш в 8:00): что сегодня, что поменялись сроки, что горит.
- Эскалация: за 3 дня дедлайн подсвечивается, за 1 день — мелькает в каждой панели.
- Правило «нет невидимых дедлайнов»: всё с датой из любой сферы видно в ленте Календаря.

### 3.4. Календарь и встречи

- Неделя/месяц: события + дедлайны на одной сетке (встречи — блоки, дедлайны — маркеры наверху).
- Встреча: название, дата-время, длительность, ссылка (Google Meet/Discord), заметки, чеклист «подготовиться» (опционально, с напоминанием за час).
- Перетаскивание задачи в календарь = time-blocking (назначить слот на дело). Слот подсвечен на сетке, за 10 минут — напоминание «начать».
- Мини-виджет «ближайшее событие: через 35 мин» на дашборде.

### 3.5. Таймеры и фокус

- **Pomodoro** (25/5, настраиваемые) с привязкой к задаче → время учитывается в аналитике сферы.
- Секундомер (для учёта «сколько реально заняло ДЗ» — калибровка будущих оценок).
- Обратный отсчет («быстро проверить тикет — 10 минут»).
- На дашборде и в трее/панели: текущая задача + таймер всегда перед глазами.
- Автоматическая запись: таймер завершился → время прибавилось к задаче (трудозатраты).

### 3.6. Работа — База знаний Pipster 🗂

Главный сценарий: **во время тикета за ≤5 секунд найти шаблон, скопировать, вставить**.

- Статьи/шаблоны: название — суть — тело (Markdown), теги (`оплата`, `подключение`, `не работает VPN`, `iOS`, `Android`, `Windows`...), категория.
- **Мгновенный поиск** по названию, тексту и тегам уже при наборе (debounce не нужен, список локальный).
- Кнопка **«Копировать»** крупная и первая у каждой карточки.
- Избранное — сверху. Счётчик использований шаблона → сортировка «самые частые вверху».
- Переменные в шаблонах: `{имя}`, `{тиккет}`, `{дата}`, `{почта}` → при копировании открывается мини-формочка быстрой подстановки (опционально, v2).
- Секция «Быстрые ответы» отдельно от «Инструкции по продукту» (два таба).
- Поле «новая проблема, решения нет» → создавать задачу «разобраться и дописать шаблон» со сферой Работа.

### 3.7. Учеба 🎓

- **ДЗ:** карточки по предметам. Поля: предмет, что задано, дедлайн, статус (не начато / в работе / сдано / проверено), вложения/ссылки. Дедлайны ДЗ автоматически в общем календаре.
- **Предметы** как подгруппы контекста Учеба (свой цвет).
- **Конкурсы / олимпиады:** отдельная лента со статусами: 📌 слежу → 📝 готовлюсь → ✅ участвую → 🏆 результат. Обязательное поле: дедлайн подачи и дата события, два разных напоминания. Ссылка на сайт. Поле «что нужно подготовить» (чеклист).
- **Портфолио:** карточки достижений/работ: фото/файл, описание, ссылки, теги (публичное/внутреннее), год. Это витрина — сюда же «что пригодится для резюме».
- **Конспекты:** карточки-заметки + навесная связка «предмет» и «ссылки на материалы» (облако/Google Docs/Notion). Не хранить сами конспекты — хранить **их инвентарь и ссылки** + поиска по названиям.
- **Ссылки:** хранилище всех учебных URL с тегами (не забыть, зачем эта ссылка — поле «зачем»).

### 3.8. Личные проекты 🚀 (мобильное приложение)

- Проект = карточка: цель, статус (идея / в разработке / бета / релиз / пауза), дедлайны вех.
- **Роадмап:** колонки **Сейчас / Дальше / Потом / Готово** (Kanban). Задачи роадмапа — обычные задачи со сферой «Проекты» и привязкой к проекту: дедлайны видны в общей системе.
- **Идеи (Инкубатор):** лента идей с полями: текст (быстрый захват), сфера, теги, статус: 💡 новая → 🔍 изучаю → ✅ в роадмапе → ❌ отклонена. Кнопка «перевести в задачу/в роадмап» превращает идею в элемент бэклога.
- Разделить захваченные идеи: копится всё подряд (голосом в лифте про себя), разбор — раз в неделю на Обзоре.
- **Идеи улучшений** ( BUG/UX/perf ) — тот же инкубатор с тегом типа.
- **Журнал релизов:** что выпустил, что заметили пользователи.
- Идеи могут приходить из дома сферы (например, из Жизни: «в метро пришла фича») — одна база идей, разные источники.

### 3.9. Личная жизнь ❤️

- **Журнал:** краткие записи дня (текст/настроение/фото), теги. Поле «что было хорошо / что мешало» (по желанию). Используется в еженедельном Обзоре.
- **Личные дела:** обычные задачи (записаться к врачу, поздравить...). Шаблоны повторяющихся: «позвонить родителям» и т.п.
- **Встречи/свидания/звонки:** через общий Календарь (сфера Личное). Плюс поле «важная дата» (дни рождения) — годовые повторения с напоминанием за 3 дня.
- **Дни рождения nearby widget**: блок на дашборде.

### 3.10. Входящие (Inbox) 📥

- Всё, что захвачено хоткеем/кнопкой/виджетом, попадает сюда без заполнения полей.
- Разбор ленты: каждой записи даём сферу / превращаем в задачу / удаляем. Достижима цель — inbox empty за 5 минут в неделю.
- Счётчик неразобранного виден в меню (плохо, когда растет).

### 3.11. Еженедельный обзор (ритуал 15 минут) 🔁

Проводник из шагов:
1. Входящие → разобрать все.
2. Просроченные → перенести или отозвать.
3. Дедлайны ближайших 2 недель — что уже можно начать?
4. Идеи → за/против/в роадмап.
5. Быстрая аналитика: где провёл время, что сделал, что переносил больше 2 раз (требует решения или чтения).
6. Выбрать 1–3 главных цели на неделю.

### 3.12. Аналитика 📊

- «Сколько времени ушло на каждую сферу за неделю» (из таймеров) — важно, чтобы работа не съела все личные проекты.
- Выполнено / просрочено / перенесено (по сферам, в динамике недель).
- Среднее время выполнения ДЗ по предмету → точнее планировать.
- Использование шаблонов Pipster: ТОП-10 самых нужных.
- Скорость улучшения: сколько идей ушло в роадмап за месяц.

### 3.13. Глобальный поиск и захват 🔎

- Поиск: по названию, тексту, тегам, сферам. Сущности: задачи, шаблоны, идеи, ДЗ, заметки, ссылки. Результат — единый список с иконкой типа.
- **Хоткей захвата (Ctrl+Shift+A и т.п.):** окно сверху экрана → текст → Enter → во Входящие. Это самая используемая функция в системе.

## 4. Правила UX

- Холодный старт < 2 сек, всё локально, оффлайн-first (синхронизация — опционально, v2+).
- Добавить задачу из любого экрана — не более 2 касаний; поля заполняются потом на карточке.
- Дата вводится по-человечески: «завтра», «в пн», «через 3 дня», «20 окт».
- Свайп вправо = сделано, свайп влево = отложить, длинное нажатие = меню.
- Клавиатурное управление продублировано (desktop-версия чуть быстрее мышью).
- Цвет сферы пропитывает всю карточку (полоса слева) — даёт мгновенное понимание, где находишься.
- Тёмная/светлая тема. Уведомления категории «горящий дедлайн» нельзя замьютить случайно.

## 5. Порядок реализации (MVP → v2 → v3)

**MVP (недели 1–2):**
1. Сферы, задачи с дедлайнами и напоминаниями, статусы.
2. Дашборд «Сегодня» с просроченными и дедлайнами.
3. База знаний Pipster с поиском и «копировать».
4. Inbox + глобальный захват.
5. Календарь (только лента дедлайнов, без перетаскивания).

**V2:** встречи, роадмап и Проекты, ДЗ/конкурсы в Учебе, таймеры/Pomodoro, повторения, еженедельный обзор.

**V3:** аналитика, портфолио/конспекты-ссылки, журнал, шаблоны с переменными, time-blocking drag'n'drop, синхронизация устройств, виджеты/пуши ОС.

---

## 6. Ключевые ловушки (что НЕ делать)

- ❌ Не строить «систему PM» с эпиками/спринтами — она для одного человека, гибкость > методологии.
- ❌ Не делать все поля обязательными — умрёт за неделю.
- ❌ Не разделять следящие экраны по сферам так, что дедлайны из одной сферы не видны в другой — это причина №1 потери сроков.
- ❌ Не хранить тектонические заметки без даты (конспекты)) — без ссылок на предмет/источник превращаются в свалку.
- ❌ Не делать идею, где есть 2 способа попасть в задачу (интерфейс двойного входа) — у каждой сущности один четкий путь.

## 7. ГОТОВЫЙ КОРОТКИЙ ПРОМПТ (копировать в ИИ/агента)

> Создай приложение личного тайм-менеджмента. Пользователь: студент, работает в техподдержке VPN («Pipster»), разрабатывает собственное мобильное приложение. Жизнь делится на 4 сферы: Работа, Учеба, Личные проекты, Личное — контекст на цветах, обязательный для каждой записи.
>
> Ядро 1 — Задачи: название (только оно обязательное), сфера, дедлайн, напоминание с настраиваемым опережением, приоритет (срочно-важно/обычное/когда-нибудь), повторение, оценка времени, подзадачи, статусы Входящие→Сегодня→В работе→Сделано. Свайпы: справо=готово, влево=отложить (+1/+3/след. неделя).
>
> Ядро 2 — Единые дедлайны: любой объект (задача, ДЗ, конкурс, встреча, релиз) имеет срок + напоминания; утренний пуш-дайджест; эскалация подсветки за 3 дня/1 день. Один общий календарь всех сфер — дедлайны не прячутся внутри сфер.
>
> Экраны: (1) Дашборд «Сегодня»: просроченные, дедлайны дня, встречи дня, «3 главных дела», ближайшее событие, быстрые кнопки +задача/+идея/+встреча/+таймер, переключатель приоритетной сферы по времени суток. (2) Календарь нед/мес с событиями и дедлайнами, drag задачи = time-blocking. (3) База знаний Pipster: шаблоны ответов с мгновенным поиском по названию/тегам/тексту, крупная кнопка «Копировать», избранное, счётчик использования, разделы «Быстрые ответы» и «Инструкции», теги по проблемам/платформам. (4) Учеба: ДЗ по предметам (статус до/в работе/сдано/проверено, дедлайн), конкурсы (статусы слежу→готовлюсь→участвую→результат, дедлайн подачи и дата события, чеклист подготовки), портфолио карточками, инвентарь конспектов со ссылками, хранилище ссылок с полем «зачем». (5) Проекты: карточка проекта + роадмап-канбан «Сейчас/Дальше/Потом/Готово», инкубатор идей (статусы новая→изучаю→в роадмапе→отклонена, кнопка «стать задачей»), журнал релизов. (6) Личное: журнал дня, личные дела, важные даты с годовым повторением (дни рождения, напоминание за 3 дня). (7) Входящие: захват без полей, разбор ленты.
>
> Сервисные функции: глобальный хоткей быстрого захвата в Inbox; глобальный поиск по всем сущностям; таймеры Pomodoro/секундомер/обратный отсчет с привязкой к задаче и учётом времени; еженедельный обзор-проводник (разобрать inbox → просроченные → дедлайны 2 недель → идеи → аналитика → цели недели); аналитика распределения времени по сферам, выполнено/просрочено/перенесено, точность оценок ДЗ, ТОП используемых шаблонов.
>
> Принципы: только поле «название» обязательно; оффлайн-first, локально; захват первичен, разбор вторичен; запись не удаляется, а архивируется; минимум ритуалов — только утренний план и недельный обзор; один путь к каждой сущности, без дублирования.
>
> Порядок: MVP = сферы + задачи с дедлайнами + дашборд + база знаний + inbox; затем календарь/встречи/роадмап/ДЗ/таймеры; затем аналитика/журнал/синхронизация.
