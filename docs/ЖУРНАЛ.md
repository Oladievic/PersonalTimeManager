# Журнал работы над «Пробкой»

## Что это за проект

Личный «второй мозг + командный центр» в виде пробковой доски с наклейками и нитями.
Один пользователь, четыре сферы: Работа (поддержка VPN Pipster), Учёба, Проекты (мобильное приложение), Личное.
Технически — офлайн-first PWA: один код на Windows и Android, данные локально (IndexedDB), без сервера.

Папка: `D:\Personal Time Manager`

## Ключевые решения

1. **PWA вместо нативного приложения.** Node/Flutter/Android SDK на машине нет. PWA запускается сразу, работает офлайн, ставится на Android и Windows. Позже пакуется в APK через Capacitor без переписывания.
2. **Доска — не единственный экран.** Наклейки остаются визуальным слоем, но данные общие: та же запись видна и на доске, и в списках «Сегодня», «Задачи», «Входящие».
3. **Одна сущность `note`.** Тип (`kind`) определяет, задача это, шаблон, ДЗ, конкурс, идея, встреча, журнал или проект. Сфера (`sphere`) — обязательный контекст.
4. **Только название обязательно.** Быстрый захват создаёт запись в Inbox без полей; остальное заполняется в карточке.
5. **Ничего не удаляется сразу.** Архив + отмена действий + резервные копии.
6. **Дедлайн — универсальное свойство.** Единый `due` для всех типов, общий календарь и повестка.
7. **Один вход к сущности.** Список → карточка деталей; доска → та же карточка. Дублирующих сценариев не делаем.

## Ограничения, о которых помним

- Уведомления работают, пока приложение открыто (в фоне PWA без push-сервера ненадёжны). Это записано в README.
- Глобальный хоткей ОС недоступен из браузера; внутри приложения — Ctrl+Shift+A. Для системного хоткея нужна обёртка (Capacitor/Tauri).
- Синхронизация между устройствами не входит в MVP: перенос через файл `.probka`.
- Мобильные свайпы: делаем кнопки-дубли, свайпы — если останется время.

## Следующие шаги

1. `overlays.js`: модальные окна, меню, настройки доски, нить, подтверждения.
2. `views.js`: 10 экранов ТЗ.
3. `panels.js`: поля сферы/типа/статуса/напоминания/оценки времени/повторения, шаблоны.
4. `tools.js`: захват, поиск, повестка, архив, бэкапы, таймер, напоминания, экспорт.
5. `main.js`: инициализация, горячие клавиши, тема, PWA.
6. `manifest.webmanifest`, `sw.js`, иконки, `README.md`, `serve.py`, `run.bat`.
7. Проверка в браузере: скриншоты, консоль, сценарии.
