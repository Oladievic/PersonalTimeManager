# Журнал работы над «Пробкой»

Обновлено: 2026-10-25

## Что это за проект

Личный «второй мозг + командный центр» в виде пробковой доски с бумажками и нитями.
Один пользователь, четыре сферы: Работа (поддержка VPN Pipster), Учёба, Проекты (мобильное приложение), Личное.

Технически — офлайн-first PWA: один код для Windows и Android, данные локально в IndexedDB, без обязательного сервера. Сервер на Python добавляет REST-синхронизацию и MCP-доступ для ChatGPT/Claude.

Папка: `D:\Personal Time Manager`

## Ключевые решения

1. **PWA вместо нативного приложения.** Node/Flutter/Android SDK на машине нет. PWA запускается сразу, работает офлайн, ставится на Android и Windows. Позже пакуется в APK через Capacitor без переписывания кода.
2. **Доска — главный экран.** При запуске всегда открывается доска. «Сегодня», «Задачи», «Календарь» и сферы остаются вспомогательными представлениями тех же данных.
3. **Одна сущность `note`.** Тип (`kind`) определяет, задача это, шаблон, ДЗ, конкурс, идея, встреча, журнал или проект. Сфера (`sphere`) — контекст.
4. **Только название обязательно.** Быстрый захват создаёт запись в Inbox без полей; остальное заполняется в карточке.
5. **Ничего не удаляется сразу.** Архив + отмена действий + резервные копии.
6. **Дедлайн — универсальное свойство.** Единый `due` для всех типов, общий календарь и повестка.
7. **Один вход к сущности.** Бумажка на доске и список открывают одну и ту же подробную карточку.
8. **Краткое на доске, полное в карточке.** Бумажка показывает название и 2–3 строки описания; полный HTML, ссылки и файлы не перегружают доску.

## Ограничения, о которых помним

- Уведомления работают, пока приложение открыто (в фоне PWA без push-сервера ненадёжны).
- Глобальный хоткей ОС недоступен из браузера; внутри приложения — Ctrl+Shift+A. Для системного хоткея нужна обёртка (Capacitor/Tauri).
- Синхронизация между устройствами разрешает конфликты по времени изменения, а не по смыслу.
- Вложения не передаются через MCP.
- ChatGPT требует публичный HTTPS; туннель — внешний сервис.
- Это персональный инструмент, а не многопользовательская система.
