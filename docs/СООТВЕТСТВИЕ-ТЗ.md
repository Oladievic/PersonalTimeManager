### 3.2 Задачи

## 5. Порядок реализации

MVP по ТЗ: сферы + задачи + дедлайн/напоминания, «Сегодня», база Pipster, Inbox, календарь-лента.  
Фактический порядок: сначала дизайн-каркас и доска (уже), затем MVP-экраны, затем v2 (проекты/учёба/таймеры), затем аналитика.
