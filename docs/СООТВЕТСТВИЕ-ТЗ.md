## 5. Порядок реализации

Фактически сделано: дизайн-каркас → доска → подробная карточка и анимация → MVP-экраны → сферы/проекты/учёба/таймеры → аналитика → PWA → синхронизация и MCP.

## 6. Анти-паттерны

- ✅ нет эпиков/спринтов — только записи, сферы, проекты
- ✅ нет обязательных полей кроме названия
- ✅ дедлайны всех сфер видны в общих представлениях
- ✅ у сущности один путь редактирования — подробная карточка
- ✅ конспекты не хранятся целиком, только инвентарь ссылок

## 7. Осознанные ограничения

1. **Уведомления** — только при открытом приложении. Для фоновых нужен push-сервер или нативная обёртка.
2. **Глобальный хоткей ОС** — недоступен из браузера; внутри приложения Ctrl+Shift+A.
3. **Синхронизация** — не конфликт-менеджер по смыслу; побеждает более свежая запись.
4. **MCP** — не передаёт вложения; тексты, сроки, чек-листы и поля доступны.
5. **ChatGPT** — требует публичный HTTPS-туннель; это внешний сервис.
6. **Многопользовательская работа** — не поддерживается; инструмент персональный.
